# Instituto Esperança

Projeto front-end desenvolvido para uma organização sem fins lucrativos, com o objetivo de apresentar projetos sociais e facilitar a participação de voluntários e doadores.

## Funcionalidades

- Navegação entre as páginas da aplicação
- Navegação em formato SPA utilizando JavaScript
- Apresentação dos projetos sociais
- Formulário de cadastro
- Elementos de feedback visual
- Layout responsivo
- Estrutura semântica e recursos de acessibilidade

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
